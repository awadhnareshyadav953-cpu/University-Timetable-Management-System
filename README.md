
# University Timetable Management System

## Project Description
This is a mini project developed using C programming.
It displays the weekly university timetable for students.

## Features
- Displays timetable from Monday to Saturday.
- Shows three subjects per day.
- Displays lecture timings.
- Simple and easy to use.

## Programming Language
C Language

## Concepts Used
- Arrays
- 2D Arrays
- Loops
- Strings
- printf() function

## How to Run
1. Open the C compiler.
2. Compile timetable.c.
3. Run the program.
4. View the university timetable.

## Conclusion
This project helps students view their weekly
class schedule easily and clearly.
